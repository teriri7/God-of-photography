# 摄影之神 (God of Photography)

> **专为摄影师与修图爱好者打造的移动端 AI 图层创作与专业级后期工作台**  
> 融合类 Photoshop 多图层编辑、Adobe Camera Raw 级专业影调调节、智能场照除杂与多模态 AI「半合成」生图引擎。

---

## 📱 软件功能全览

### 1. 🎨 精致粉色玻璃拟态界面 (Pink Glassmorphism)
- 采用柔美樱花粉与半透明毛玻璃质感，专为移动端单手操作优化。
- **自适应视窗联动**：当展开「图层调整」或「画面影调」时，主画布自动平滑收缩至紧凑预览模式（~60%），并智能折叠其他菜单，方便一边拖动调节滑杆，一边实时观察画面细微变化。
- **电脑端手机模拟器**：在电脑浏览器调试时提供逼真的手机外壳与灵动岛视口，并支持一键切换宽屏。

### 2. 📑 类似 Photoshop 的多图层管理
- **非破坏性图层系统**：支持随时导入多张照片作为不同图层。
- **自由图层堆叠**：支持图层上下移动交换图层层级次序。
- **显隐与透明度**：单键切换图层眼睛图标，0% ~ 100% 精确不透明度滑杆。
- **图层快捷复制与删除**：方便进行多图层效果对比或备份。
- **AI 结果自动压栈**：每次 AI 生成的新图片均自动封装为全新图层，保留底层原图完好无损。

### 3. 🎛️ 专业级 Camera Raw 画面影调调色引擎
提供比拟 Adobe Camera Raw / Lightroom 的 9 大核心影调与色彩控制，全像素实时精准运算：
- **曝光 (Exposure)**：宽容度曝光调节。
- **对比度 (Contrast)**：以中间调为基准的高低对比调整。
- **高光 (Highlights)**：压制过曝死白，找回亮部层次细节。
- **阴影 (Shadows)**：提亮暗部死黑，呈现暗部细腻纹理。
- **白色 (Whites)**：调整画面最亮端点动态范围。
- **黑色 (Blacks)**：调整画面最暗纯黑端点深邃度。
- **色温 (Temperature)**：冷蓝到暖橙白平衡校正。
- **色调 (Tint)**：偏绿到偏洋红的微妙色彩倾向修正。
- **饱和度 (Saturation)**：色彩鲜艳度与灰度控制。
- **一键重置**：随时一键恢复当前图层初始影调。

### 4. 🪄 独创 AI「半合成」工作流 (场照除杂 + 角色布景)
专为漫展场照、COS 外拍、日常写真设计的专业级落地修图管线：
- **第一步：场照智能除杂**
  - 自动识别并完全移除画面中非结构穿帮元素（路人、观众、摄影灯架、反光板、柔光箱、线缆胶带、地面垃圾杂物）。
  - 周围背景纹理与光影无缝修补，严格锁定模特人物面部、服装与姿势不变。
- **第二步：角色与道具识别 (LLM 视觉多模态大模型)**
  - 自由选择视觉分析大模型，点击「开始识别」分析图片角色设定、原著出处、环境特征。
  - 自动生成符合真实物理落地的合成道具建议（如法阵符文、武器浮空纹理、环境光斑、花瓣风动等），杜绝悬浮虚假感。
- **第三步：道具选择与细节配置**
  - 自由勾选或新增道具，支持画幅比例匹配与 2K / 4K 超高精度生成。
- **第四步：生图并一键载入新图层**
  - 自动调用图生图大模型，并将渲染结果自动压入当前项目图层。

### 5. ⚙️ 多线路 API 节点管理与模型自由切换
- **多 API 线路支持**：可在设置中配置多个不同中转站（NewAPI 等），自定义线路名称与 API Key，并在主界面与半合成弹窗中随心秒切。
- **动态拉取模型**：支持一键拉取服务商提供的全部图像与多模态模型列表。
- **画幅比例自动匹配**：导入任意分辨率原图（如 4000×6000），系统自动智能匹配 2:3、3:2、1:1、9:16、16:9、3:4、4:3 等最契合的画幅比例。
- **全参数持久化记忆**：选择的模型、分辨率（1K/2K/4K）、画幅比例均自动本地缓存，下次启动自动恢复。

### 6. 💾 4K 超高清全图层无损合成导出
- 一键将所有可见图层、不透明度、混合模式及 Camera Raw 调色矩阵进行像素级复合渲染。
- 直接保存高质量 PNG 图片到手机相册或电脑存储。

## 📦 打包与安装说明

### 云端自动打包 Android APK (推荐)
本项目已完整配置 GitHub Actions 持续集成流水线：
1. Fork 或上传本项目到你的 GitHub 仓库。
2. 进入仓库页面的 **Actions** 标签页，工作流将在提交代码后自动执行打包（也可手动点击 `Run workflow` 触发）。
3. 编译完成后，在构建产物 (Artifacts) 列表中直接下载 **`摄影之神-APK`**。
4. 发送至安卓手机即可直接安装运行。

### 本地开发与构建
```bash
# 安装依赖 (建议 Node.js >= 22.0.0)
npm install

# 启动本地热重载调试
npm run dev

# 编译 Web 生产产物
npm run build

# 同步到 Android Capacitor 原生项目
npx cap sync android
```
